❓ QUESTIONS RAPIDES
=================================================================================

Q: Les produits ne s'affichent pas?
A: Vérifier dans MySQL:
   SELECT COUNT(*) FROM products WHERE is_available = 1;
   Doit retourner > 0

Q: Les images ne s'affichent pas?
A: Vérifier que Cloudinary est configuré
   Consulter src/config/cloudinary.js

Q: Les filtres ne fonctionnent pas?
A: Ouvrir Console (F12)
   Vérifier pas d'erreur JS
   Vérifier Network: GET /api/marketplace/products

Q: Pagination ne marche pas?
A: Vérifier que produits > 20
   Pagination n'apparaît que si résultats > 20

Q: Comment ajouter des données test?
A: Voir MARKETPLACE_GUIDE.md section "TESTS DONNÉS"

=================================================================================
🔧 DÉPANNAGE RAPIDE
=================================================================================

ERREUR: "Cannot GET /marketplace"
→ Vérifier que app.js a les routes marketplace
→ Redémarrer serveur: npm start

ERREUR: "Cannot find module 'marketplaceService'"
→ Vérifier fichier src/services/marketplaceService.js existe
→ Vérifier syntaxe: node --check src/services/marketplaceService.js

ERREUR: MySQL "Unknown column 'city' in users"
→ Vérifier migration exécutée: 006_marketplace_support.sql
→ Vérifier colonnes: SHOW COLUMNS FROM users LIKE 'city';

ERREUR: Images en 404
→ Vérifier Cloudinary configuré
→ Vérifier URLs dans DB: SELECT image_url FROM products LIMIT 1;

ERREUR: Filtres ne mettent pas à jour
→ Ouvrir F12 Console
→ Vérifier pas d'erreur JS
→ Vérifier Network: requête /api/marketplace/products
→ Vérifier status 200 sur réponse
