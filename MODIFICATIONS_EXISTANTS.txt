3. src/config/upload.js (Configuration upload)
================================================================================

MODIFICATIONS APPORTÉES:
- Export d'une nouvelle fonction utilitaire: getImageUrl()

DÉTAILS:

Avant (lignes 45-52):
```javascript
module.exports = {
  upload,
  MAX_FILE_SIZE
};
```

Après (lignes 45-55):
```javascript
module.exports = {
  upload,
  MAX_FILE_SIZE,
  /**
   * Retourne l'URL complète de l'image
   * Supporte les URLs Cloudinary et les chemins relatifs
   */
  getImageUrl: (url) => {
    if (!url) return '/images/placeholder.png';
    if (url.startsWith('http')) return url;
    return url;
  }
};
```

IMPACT:
- Zéro impact - Ajout fonctionnalité sans modification existante
- Fonction purement utilitaire
- Fallback sur placeholder.png si vide
- Compatible avec Cloudinary et chemins relatifs
