PUBLIC ROUTES (No Auth Required)
───────────────────────────────────────────────────────────────────────────

1. GET /marketplace
   Description: Page d'accueil du marketplace
   Response: HTML EJS (marketplace/home.ejs)
   Data Props:
     - popularProducts: Array<{id, name, price, currency, image_url, business_name, store_slug, city, country, share_token}>
     - recentProducts: Same structure
     - recommendedStores: Array<{business_name, store_slug, city, country, product_count, total_views}>
     - trendingCategories: Array<{name, slug, product_count}>

2. GET /marketplace/products
   Description: Page de liste des produits avec filtres
   Query Parameters:
     - search (string): Recherche textuelle
     - category (string): Slug de catégorie
     - city (string): Nom de ville
     - country (string): Code/nom pays
     - minPrice (number): Prix minimum
     - maxPrice (number): Prix maximum
     - sort (string): recent|popular|price_low|price_high|rating (default: recent)
     - limit (number): Items par page (default: 20)
     - offset (number): Offset pagination (default: 0)
   
   Example: GET /marketplace/products?category=electroniques&city=Douala&sort=popular&limit=20&offset=0
   
   Response: HTML EJS (marketplace/products.ejs)
   Data Props:
     - products: Array<Product>
     - total: number (total de produits)
     - filters: {search, category, city, country, minPrice, maxPrice, sort, limit, offset}
     - categories: Array<{name, slug, product_count}>
     - cities: Array<{city, product_count}>
     - countries: Array<{country, product_count}>

3. GET /marketplace/stores
   Description: Page de liste des boutiques avec filtres
   Query Parameters:
     - city (string)
     - country (string)
     - sort (string): recent|popular|verified (default: recent)
     - limit (number): (default: 20)
     - offset (number): (default: 0)
   
   Example: GET /marketplace/stores?city=Yaoundé&sort=popular
   
   Response: HTML EJS (marketplace/stores.ejs)
   Data Props:
     - stores: Array<Store>
     - total: number
     - filters: {city, country, sort, limit, offset}
     - cities: Array
     - countries: Array

================================================================================
                         STATUS CODES & ERRORS
================================================================================

200 OK
   ✓ Requête réussie
   Response: { success: true, data: {...}, message: "..." }

400 Bad Request
   ✗ Paramètres invalides
   Response: { success: false, error: "...", statusCode: 400 }

404 Not Found
   ✗ Ressource non trouvée
   Response: { success: false, error: "...", statusCode: 404 }

500 Internal Server Error
   ✗ Erreur serveur
   Response: { success: false, error: "Internal Server Error", statusCode: 500 }

429 Too Many Requests
   ✗ Rate limit atteint
   Response: { success: false, error: "Too many requests", statusCode: 429 }

================================================================================
                         EXEMPLE DE FLUX CLIENT
================================================================================

1. Utilisateur visite /marketplace
   ↓
   Charger page d'accueil avec sections pré-remplies

2. Utilisateur clique "Voir tous les produits"
   ↓
   Redirection vers /marketplace/products

3. Utilisateur sélectionne filtres:
   - Catégorie: "Électroniques"
   - Ville: "Douala"
   - Tri: "Populaires"
   ↓
   JavaScript marketplace-products.js déclenche:
   fetch('/api/marketplace/products?category=electroniques&city=Douala&sort=popular&limit=20&offset=0')
   ↓
   Reçoit JSON
   ↓
   Met à jour DOM avec produits

4. Utilisateur clique "Suivant" (pagination)
   ↓
   JavaScript calcule offset = 20
   ↓
   fetch('/api/marketplace/products?...&offset=20')
   ↓
   Scroll en haut de page
   ↓
   Grille mise à jour

================================================================================
                         CONFIGURATIONS
================================================================================

Rate Limiting (publicLimiter):
   - Limite: ~100 requêtes / 15 minutes
   - Appliqué à tous les routes /marketplace/*
   - Configuration: src/middlewares/rateLimiter.js

Database Indices:
   - users.city (INDEX)
   - users.country (INDEX)
   - products.category_id (FOREIGN KEY)
   - categories.slug (UNIQUE + INDEX)

Pagination:
   - Par défaut: 20 items par page
   - Max: 100 items par page
   - Min: 1 item par page

Cache:
   - Pas de cache côté client par défaut
   - Recommandé: Implémenter cache HTTP pour images

================================================================================
                         DÉPANNAGE
================================================================================

Q: La page /marketplace/products affiche "Aucun produit trouvé"
A: Vérifier que:
   1. Des produits existent dans DB (is_available = 1)
   2. Les vendeurs sont actifs (users.is_active = 1)
   3. Les paramètres de filtre ne sont pas trop restrictifs

Q: Les images des produits ne s'affichent pas
A: Vérifier que:
   1. Cloudinary est configuré (src/config/cloudinary.js)
   2. Les URLs d'image commencent par "https://" ou sont des chemins relatifs
   3. getImageUrl() est appelé correctement

Q: Le tri "par rating" ne fonctionne pas
A: Actuellement, le rating utilise view_count comme proxy
   (Implémenter un système de rating réel est optionnel)

Q: Pagination affiche "prev" désactivé avec offset=0
A: Normal - c'est la première page

Q: Rate limit atteint (429)
A: Attendre 15 minutes ou
   Augmenter limite dans src/middlewares/rateLimiter.js
